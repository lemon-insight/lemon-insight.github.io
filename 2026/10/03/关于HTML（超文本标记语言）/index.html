介绍 HTML 的基本概念、核心语法与常见标签，作为前端入门的第一站。

一、什么是 HTML

HTML（HyperText Markup Language，超文本标记语言）是用于创建网页的标准标记语言。它通过一系列标签（Tag）来描述网页的结构和内容，浏览器解析 HTML 文档后渲染出我们看到的页面。

  • 超文本：超越纯文本，可以包含图片、链接、音频、视频等
  • 标记：用标签标记内容的不同部分，如标题、段落、列表等

HTML 是网页的骨架，CSS 负责样式，JavaScript 负责交互。

二、基本结构

一个标准的 HTML5 文档结构如下：

部分 说明
<!DOCTYPE html> 声明文档类型为 HTML5
<html> 根元素，包含整个页面
<head> 元信息区域，不直接显示在页面上
<meta charset="UTF-8"> 指定字符编码为 UTF-8
<title> 浏览器标签页显示的标题
<body> 页面主体内容区域
