介绍 CSS 的基本概念、语法规则、选择器与常用属性，作为前端入门系列第二站。

一、什么是 CSS

CSS（Cascading Style Sheets，层叠样式表）是一种用于描述 HTML 或 XML 文档呈现方式的样式表语言。CSS 描述了元素在屏幕、纸张或其他媒体上的渲染方式。

  • 层叠：多个样式规则按优先级和特异性叠加，最终生效
  • 样式表：一组控制网页外观的规则集合

CSS 与 HTML、JavaScript 并称为万维网核心技术。HTML 负责结构，CSS 负责表现，JavaScript 负责行为。

二、CSS 引入方式

方式 语法 适用场景
内联样式 style="color: red;" 单个元素临时样式
内部样式表 <style> 标签 当前页面
外部样式表 <link rel="stylesheet" href="style.css"> 多页面共享

推荐优先使用外部样式表，实现结构与表现分离。

三、基本语法

  • 选择器：选中要设置样式的元素
  • 属性：要改变的样式特性（如颜色、大小）
  • 值：属性的具体设置

四、选择器

4.1 基础选择器

选择器 示例 说明
元素选择器 p { } 选中所有<p>
类选择器 .intro { } 选中 class=”intro” 的元素
ID 选择器 #header { } 选中 id=”header” 的元素
通配符 * { } 选中所有元素
后代选择器 div p { } 选中 div 内的所有 p
子选择器 div > p { } 选中 div 的直接子级 p

六、优先级与继承

6.1 优先级（从高到低）

  1. !important（尽量避免使用）
  2. 内联样式 style=""
  3. ID 选择器 #id
  4. 类选择器、属性选择器、伪类 .class / [type] / :hover
  5. 元素选择器、伪元素 div / ::before
  6. 通配符 *
  7. 继承的样式（最低优先级）

6.2 继承

部分属性会从父元素继承到子元素：

  • 可继承：color、font-family、font-size、line-height、text-align
  • 不可继承：width、height、margin、padding、border
