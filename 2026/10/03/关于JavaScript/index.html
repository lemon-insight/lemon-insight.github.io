一、什么是 JavaScript

JavaScript 是一种轻量级、解释型的编程语言，主要用于网页开发。它与 HTML、CSS 并称为万维网核心技术：HTML 负责结构，CSS 负责样式，JavaScript 负责交互与行为。

  • 解释型：不需要编译，浏览器直接执行
  • 动态类型：变量类型在运行时确定
  • 基于原型：支持面向对象编程
  • 事件驱动：通过事件处理用户交互

JavaScript 不仅用于浏览器，也可通过 Node.js 在服务端运行，实现全栈开发。
